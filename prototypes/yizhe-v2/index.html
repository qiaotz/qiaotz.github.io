预习 4 屏

选科目章节（逐级目录）→ 章节概览 / 知识地图（节点可点）→ 真实 3 题检测（可跳过 / 提交）→ 薄弱清单结果页 →「去上课解决这些问题」。老用户先见「继续预习」。

上课 2 屏

任务列表与知识点详情拆页 · 视频倍速 / 字幕 / 进度记忆 / 章节节点 · 图文讲义 / 易混点 / 我的笔记 · AI 降为上下文辅助 · 微测 1/3→3/3 真实推进，达标后才开放「去做题验证」· 低权重「仍未理解」反馈。

做题 5 屏

今日推荐练习 → 单题作答（逐题切换 / 收藏 / 猜测标记 / 本题笔记自动保存）→ 单题解析（标准 / AI 分层 / 我的笔记，权重提示）→ 整组结果按表现给唯一推荐动作 · 真题/模考一行轻入口，无固定开考时间。

复习 3 屏

今日到期 6 张卡 → 主动回忆卡（默认隐藏答案，语音作答 / 查看笔记记为辅助）→ 查看答案后才出现「记住了 / 模糊 / 忘记」→ 结果页给数量与下次安排 · 无到期时只推荐一个主动作。

改错 7 屏

今日待改错 + 五类真实筛选列表 → 错题详情 + AI 建议原因（用户确认）+ 三字段改错记录 → 待间隔重做（24h，可演示模拟）→ 原题乱序重做 → 2 道同类题验证 → 已消灭。保存原因不再直接完成。

笔记中心 2 屏 + 抽屉

列表仅摘要（标题 / 摘要 / 来源 / 知识点 / 状态）· 真实搜索与双排筛选（含无结果与清除）· 待处理区集中确认 AI 整理 · 详情页版本对比「编辑后采用 / 采用并保存 / 暂不采用」· 底部新建（文字 + ASR，OCR/AI 整理标注 P1）· 软删除可恢复。

我的 9 屏

菜单三组（学习资产 / 计划与提醒 / 账号与服务）· 会员多状态（未开通 / 试用 / 已开通 / 将到期 / 已过期）+ 支付弹层（成功 / 取消 / 失败）· 价格权益标注示例配置 · 数据导出与账号注销 · 全部菜单可进入子页面。

组件与状态规范 设计稿

按页面结构的骨架屏 · 无任务 / 无结果 / 内容下架 / 离线待同步 / 同步冲突 · AI 无依据 / 拒答 / 限流 · ASR / 上传 / 权限长期拒绝 · 支付失败与到期提醒 · Toast 安全区规范。定位为设计规范页。
